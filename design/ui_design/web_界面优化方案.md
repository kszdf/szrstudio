# 慧根堂短视频生产工作台 · Web 界面优化方案（UI Designer / 像素君）

> 说明：上一版按「移动端消费 App」设计方向有偏差。本方案基于**现有 8385 工作台（rewrite_studio.html）真实结构**做桌面端 Web 优化，终端用户是内容运营（你/同事），不是对外发布端。
> 原始 brief 的「短视频场景模块」在此语境下映射为：视频流浏览→素材/作品库、视频播放→右栏成片预览、个人中心→项目/账号中心、内容发布→分发出口、单手操作→高频就近 + 快捷键 + 顶栏常驻、广告位/品牌区/电商入口→挂车配置位 + 品牌栏 + 收益卡。

## 一、现有界面诊断（基于真实代码）

现有 `rewrite_studio.html`（v20250729-7）：
- **结构**：顶部品牌栏（项目切换 + 违禁词状态 + 功能介绍）→ 首页（我的作品/数字模特网格）→ 工作室（横向 7 步导航 + 中间编辑器 + 右侧 344px 产物预览）。
- **令牌**：浅色为主（`--bg:#f4f6fb / --panel:#fff / --blue:#2f54eb`），圆角 14px，微软雅黑，已带响应式（<1024 退单列）。
- **问题（优化点）**：① 顶部导航与步骤导航双轨，入口略散；② 首页 hero 与网格信息密度可更高；③ 缺暗色主题（长时盯屏疲劳）；④ 商业化（挂车/收益）散落、未成体系；⑤ 缺统一空/加载/反馈状态。

## 二、设计系统（对齐现有令牌 + 扩展）

### 2.1 色彩（沿用并补全语义）
```
--bg:#f4f6fb; --panel:#fff; --surface:#f7f9fc; --surface-2:#eef2f8;
--border:#e7ebf2; --ink:#16202e; --muted:#69748a;
--blue:#2f54eb(主操作/品牌) --blue-d:#1d3ab8 --blue-l:#eef2ff;
--green:#15a05a(成功/已发布) --amber:#d98a06(警告/收益) --red:#e23b3b(违禁词);
--coin:#d98a06 → 独立电商金，与品牌蓝区分「内容 vs 交易」；
暗色主题：--bg:#0e1117 / --panel:#161b24 / --ink:#eef2f8（长时盯屏护眼）。
```
- 对比度：正文 `#16202e` on `#fff` ≈ 14:1（远超 AA 4.5:1）；暗色 `#eef2f8` on `#161b24` ≈ 13:1。

### 2.2 字号 / 间距 / 形状
- 字号阶梯：12 / 13 / 14 / 16 / 18 / 20 / 24 / 28 / 34（原仅零散定义，补成体系）。
- 间距 4px 基准：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48。
- 圆角沿用 10/14/18；动效统一 `cubic-bezier(.22,1,.36,1)`，仅动 transform/opacity。

### 2.3 组件库（复用现有 + 新增）
按钮（主/次/金币）、卡片、步骤导航、标签 Chip、网格卡、搜索框、状态徽标、产物预览卡、挂车条、Toast。状态覆盖：默认/悬停/选中/禁用/加载骨架/空态。

## 三、信息架构与导航

```
顶部品牌栏（常驻）
├─ 工作台首页     ← 作品库 + 模特库（= 视频流浏览/素材管理）
├─ 创作工作室     ← 7 步流水线（选题→改写→音频→模特→出片→质检→发布）
├─ 发布与分发     ← 内容发布出口（多平台/定时/数据）
├─ 项目/账号中心  ← 个人中心（项目、多账号、收益）
└─ 右侧：项目切换 + 违禁词状态(✅/⚠) + 主题 + 功能介绍
```
- **去双轨**：顶部 Tan 导航为「页面级」，工作室内部 7 步为「流程级」，层级清晰不冲突。
- **高频就近**：新建/草稿/队列在首页 hero 一步可达；步骤「自动推进」开关减少手动点。

## 四、主要页面布局与关键交互（Web 语境重映射）

### 4.1 工作台首页（= 视频流浏览 / 素材库）
- **三张 Hero 卡**：开始新作品（→选题）、继续草稿（→改写）、批量出片队列（→出片）。把最高频的三个动作前置到首屏。
- **作品网格**：卡片含缩略图（9:12 竖屏比例，贴合短视频）、时长角标、状态徽标（已发布/渲染中/草稿）、账号标签、赞数；点击进对应步骤。
- **模特库**：本地数字人 + 云端 SaaS 形象分列，标注「默认/对话/待启用」。
- **筛选/搜索**：分类 Chip + 搜索框（视频名/模特/选题），对标「视频流分类浏览」。
- 交互：hover 抬升 + 蓝边高亮；空状态引导「创建第一个作品」。

### 4.2 创作工作室（= 视频播放/编辑 + 实时预览）
- **横向 7 步导航**（sticky 常驻）：已完成步绿标、当前步蓝高亮、待做灰；点任意步可跳转；「自动推进」开关。
- **中间编辑器（改写面板）**：
  - 模式开关「独白 / 对话」——沿用你们已实现的逻辑，仅切可见性、不丢内容。
  - 三段稿（开头/正文/结尾）分块，textarea 实时编辑；**违禁词标红**高亮（amber 底 + ⚠ 提示），右下角实时计数「1 条待改」。
  - 工具栏：保存定稿 / AI 改写 / 试听 / 目标时长（自动换算字数）。
- **右侧产物预览（= 视频播放）**： sticky 跟随，含 9:16 成片预览（▶ 播放）、当前项目/模式/音色/违禁词状态、mini 音频播放器——「边改边看」降低返工。

### 4.3 发布与分发（= 内容发布入口）
- 六宫格：视频号/抖音（已授权）、快手（待授权）、定时发布、多平台同步、数据看板。
- 每个出口标注授权状态与已排条数；一键发布/定时/同步，挂车与留资组件自动带出。
- 数据看板汇总播放/互动/挂车转化，闭合「生产→分发→变现」。

### 4.4 项目 / 账号中心（= 个人中心）
- **左侧**：大头像 + 昵称认证 + 数据条（作品/获赞/粉丝）+ 多账号列表（财税号/营销号/绑定新号，一键切换并联动顶部项目）。
- **右侧**：**收益卡**（本月预计收益 + 去提现，商业化显性化）+ 项目列表（按最近/进行中/已归档/模板筛选）。
- 多账号切换即切换「选题归属 / 挂车商品 / 发布目标」，呼应现有 `topicAcct` 逻辑。

### 4.5 剪辑台（= 出片后精细加工）
- **入口**：工作室「出片」步骤 → 卡片「✂️ 进入剪辑台」→ 跳剪辑台（链路中段，不另开顶栏）。
- **三栏**：左素材库（视频/音频/字幕/挂车/背景乐，可导入）→ 中预览播放器 + 剪辑工具栏（选择/分割/删除/调速/静音/挂车标记）→ 右片段属性（时长/入出点/速度/音量/挂车开关）。
- **轨道时间轴**：视频/音频/字幕/挂车 四轨，色块区分（蓝=视频、绿=音频、紫=字幕、金=挂车），播放头可定位。挂车轨显式标出「🛒 自查手册」出现区间——让商业化位置在剪辑阶段就可见、可控。
- **链路**：底部「下一步：字幕样式 →」直通字幕页。

### 4.6 字幕样式页
- **左**：9:16 字幕实时预览（叠加字幕）+ 字幕文本列表（按时间点断句，可编辑、AI 自动断句、批量校对）。
- **右**：样式面板——字体/字号/颜色（白/金/绿/红 色板）/描边/背景/位置/动画；**预设模板**（简约白/财经金/醒目红/科技蓝）一键套用，预览实时变色。
- **链路**：底部「完成，去发布 →」直通发布页。

### 4.7 商品挂车落地页（= 电商入口承接）
- **入口**：发布页「🛒 商品挂车 → 预览挂车落地页」。
- **左**：手机框落地页预览（视频封面 + 商品卡 + 立即购买 + 信任背书「7天无理由·官方出品」），还原观众点小黄车后的真实落点。
- **右**：落地页配置——关联视频、商品名、售价、卖点标签、转化组件开关（留资 / 限时优惠券 / 信任背书），实时保存。
- **价值**：把「挂车」从一行商品卡升级为可运营的转化页；商业化不干扰创作，只在发布侧收敛。

## 五、商业化布局规范（工作台语境）

| 模块 | 位置 | 形态 | 干扰度 |
|---|---|---|---|
| **品牌区** | 顶部品牌栏 + Hero 卡配色 | 慧根堂品牌色（蓝/金）贯穿 | 极低（原生） |
| **电商入口（挂车）** | 工作室右栏「挂车商品」条 + 发布页 | 商品缩略卡 + ＋添加，按需展开 | 低（侧栏，不挡编辑） |
| **收益中心** | 账号中心收益卡 | 仅作者可见，激励生产 | 无 |
| **广告/分成** | 发布页「数据看板·广告分成」 | 数据披露，非弹窗 | 极低 |

**红线**：工作台**禁全屏广告弹窗**、禁遮挡编辑器与预览、商业化元素统一收敛在右栏/账号中心/发布页，与中央创作区物理隔离。

## 六、适配与无障碍

### 6.1 桌面多分辨率
- **大屏（≥1280）**：工作室两栏 `1fr / 380px`，右栏 sticky 跟随。
- **中屏（1024–1279）**：右栏保持 344–380px，密度舒适。
- **窄屏（<1024）**：退单列，右栏「产物预览」移到编辑区下方并加醒目分割头（沿用现有逻辑）。
- **平板（<1100）**：首页 hero / 中心栅格退单列，保证不被挤压。

### 6.2 无障碍（WCAG AA）
- 对比度正文 ≥ 4.5:1（本方案 13:1+）。
- 触控/点击目标 ≥ 44px（按钮、步骤项、Chip 达标）。
- 语义化 + 焦点环；暗色主题降长时盯屏疲劳；动效尊重 `prefers-reduced-motion`。
- 文本缩放 200% 不破版（grid + clamp 流式）。
