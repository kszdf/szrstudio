# 商业短视频应用 · 界面设计方案（UI Designer / 像素君）

> 面向商业用途的移动端短视频应用，定位「沉浸式内容消费 + 轻量创作发布 + 电商变现」。
> 设计目标：新用户零引导即可上手、单手可完成核心操作、暗色优先适配视频场景、商业化模块不干扰主体验。

---

## 一、设计基础（Design Foundations）

### 1.1 设计原则
| 原则 | 落地方式 |
|---|---|
| 暗色优先 | 视频消费天然暗背景，默认暗色主题；信息流/播放全屏沉浸，减少干扰 |
| 单手可达 | 所有高频操作（切 Tab、点赞、发布、评论、加购）集中在屏幕下半部拇指热区（见 §5） |
| 零引导上手 | 沿用抖音/快手已培养的用户心智（上滑换条、右侧操作栏、底部发布键），不新增陌生范式 |
| 商业化克制 | 广告/品牌/电商以「原生内容挂车 + 折叠卡 + 信息流原生广告」承载，不与播放争抢视觉焦点 |
| 一致性 | 全部基于下方令牌系统，组件跨页面复用，杜绝视觉碎片化 |

### 1.2 色彩系统（双主题 · WCAG AA）
```css
/* 暗色（默认） */
--bg:#0a0a0c; --surface-1:#141417; --surface-2:#1d1d22; --surface-3:#2a2a31;
--line:rgba(255,255,255,.08); --text-1:#f6f6f8; --text-2:#a6a6b0; --text-3:#6c6c76;
/* 品牌 & 语义 */
--brand:#ff5a3c;   /* 主品牌：活力珊瑚橙（主操作/品牌标识） */
--coin:#ffb020;    /* 收益/电商：琥珀金 */
--trust:#4c8dff;   /* 认证/信息 */
--success:#2ecc71; --danger:#ff4d4f; --live:#ff3b6b;
/* 明色（浅色场景：个人中心/商城/发布） */
--bg:#f4f5f7; --surface-1:#fff; --surface-2:#f0f1f4; --text-1:#141417; --text-2:#56565f;
```
- 正文对比度：暗底 `#f6f6f8` on `#0a0a0c` ≈ 17:1；明底 `#141417` on `#fff` ≈ 18:1（远超 AA 4.5:1）。
- 品牌橙 `#ff5a3c` 仅用于主操作与品牌标识，避免「AI 蓝紫霓虹」套路；电商金独立色系，与品牌橙区分「内容 vs 交易」。

### 1.3 字体系统
- **展示/标题**：Sora（几何无衬线，辨识度高，带品牌感）；
- **正文/UI**：Inter（中英文混排清晰，系统回退 PingFang SC / 微软雅黑）。
- **字号阶梯**：12 / 14 / 16 / 18 / 20 / 24 / 30 / 36，行高 1.4–1.6；标题 1.2–1.3。

### 1.4 间距与形状
- **4px 基准间距**：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48。
- **圆角**：按钮/卡片 10–14px、大卡 20px、胶囊 999px（标签/主操作）。
- **动效**：统一指数缓出 `cubic-bezier(.22,1,.36,1)`，仅过渡 transform/opacity（不动画布局属性），尊重 `prefers-reduced-motion`。

### 1.5 组件库（核心）
按钮（主/次/胶囊）、输入、卡片、底部 Tab 栏、右侧操作栏（点赞/评论/收藏/转发）、商品折叠卡、底部抽屉（评论/发布）、标签 Chip、网格、Toast、头像+认证标。状态覆盖：默认/按下/选中/禁用/加载/空态。

## 二、信息架构与导航

```
底部标签栏（单手拇指区正中下方）
├─ 首页（视频流沉浸浏览）      ★主入口
├─ 发现（搜索 + 分类 + 话题榜）  内容分发/电商入口前置
├─ ＋ 发布（居中凸起按钮）      ★创作入口（最高频创作动作）
├─ 消息（互动/订单/系统/买家）   交易与社交闭环
└─ 我（个人中心 + 小店 + 收益）  商业化与资产
```
- 5 个 Tab，中间「＋」物理凸起、面积最大，单手拇指正中即可触发——创作入口零位移成本。
- 全局手势：视频流**上滑切下一条**、**下滑回上一条**；评论/发布为**底部抽屉上滑**；返回用手势或抽屉下拉关闭。

## 三、主要页面布局与关键交互

### 3.1 首页 / 视频流（沉浸式消费）
**布局（全屏单条沉浸）**
- 顶部：半透明分段标签「关注 / 推荐 / 同城」（轻量，不抢画面）。
- 右下角浮层：作者头像 + 关注「＋」（带认证标）、点赞、评论、收藏、转发——竖向操作栏，全部在拇指热区。
- 左下角：作者名（带蓝 V）、文案（话题高亮）、BGM 滚动信息。
- 左下偏上：**商品折叠胶囊卡**（电商挂载，默认收起，点击展开购买）。
- **直播专属**：左上角「直播中」红标 + 脉冲点；商品卡常驻。

**关键交互**
1. 上滑 → 下一条；下滑 → 上一条（scroll-snap + 惯性，无按钮）。
2. 双击画面 → 点赞（爆心动画）；右侧心形 → 切换点赞态 + 计数。
3. 点评论图标 → 底部评论抽屉上滑（半屏，可继续看视频）。
4. 点商品胶囊 → 展开商品详情/小黄车（原生体验，不跳离当前视频）。
5. 长按 → 弹出「不感兴趣 / 举报 / 收藏」（渐进式披露，不占常驻空间）。

**新用户零引导点**：上滑换条、右侧心形=赞、中间＋=发，均为行业通用心智，无需教学。

### 3.2 视频播放与交互（单条详情）
- 进入即自动播（静音起播，点画面取消静音）；进度条极细，暂停时显示大播放键。
- 交互浮层与首页一致（点赞/评论/收藏/转发/商品），保证「流内」与「详情」体验一致，降低认知切换。
- 评论区支持楼层回复、作者身份标、点赞；输入区固定在抽屉底部（不被键盘遮挡，含安全区适配）。

### 3.3 发现 / 分类（内容分发 + 电商前置）
- 顶部搜索框（圆角胶囊，占位「搜索话题/商品/创作者」）。
- 横向滚动分类 Chip（推荐/财税/源头工厂/本地生活…），选中态品牌橙。
- 双列卡片流：封面 + 角标（点赞数/带货标）+ 标题 2 行截断 + 作者 + 数据。
- 商业化：带货内容在此设「🛒 带货」角标，点卡片可直达视频并挂车，自然过渡「种草→购买」。

### 3.4 发布入口与创作（创作中心）
- 触发：底部居中「＋」或「我」页「发布作品」→ **底部抽屉上滑**（不占满屏，保留上下文）。
- 8 宫格：拍摄、相册、模板、直播、带货、草稿箱、定时、多平台分发。
- 创作流程（下一步细化）：选择来源 → 剪辑/加字幕/选配乐 → **挂商品/选变现方式** → 填写标题话题 → 发布/定时/草稿。
- 关键：发布前一步即「挂车」，把电商行为前置到创作闭环，提升变现转化。

### 3.5 个人中心（资产 + 商业化）
- 头部：大圆角头像 + 昵称（认证标）+ ID/地区 + 简介（可放品牌 slogan/挂车引导）。
- 数据条：作品 / 获赞 / 粉丝 / 关注（点击可下钻）。
- 操作行：**发布作品（品牌橙主按钮）** · 收益中心（金）· 我的小店。
- **收益卡**：本月预计收益（金）＋ 去提现——把「创作者赚钱」显性化，激励持续生产。
- 作品/喜欢/收藏 三 Tab + 9:14 竖屏网格（播放量角标）。
- 商业化挂点：简介引导、收益卡、我的小店、发布即挂车，四位一体。

### 3.6 消息（交易 & 社交闭环）
- 分组：买家咨询、订单通知、系统通知、互动消息；未读红点。
- 买家咨询 / 订单通知直接打通电商，用户从「看视频→下单→问客服→收货」链路不跳出 App。

### 3.7 商城 / 小店（电商落地页）
- 品牌旗舰横幅（品牌展示区，含进店 CTA）。
- 分类 Chip + 双列商品卡（封面 + 标题 2 行 + 现价/划线价/销量）。
- 由视频商品卡、个人中心「我的小店」、发现带货角标三处统一导流至此，保证「内容 → 商品」路径一致。

## 四、商业化布局规范（不干扰核心体验）

| 模块 | 位置 | 形态 | 干扰度 |
|---|---|---|---|
| **原生信息流广告** | 发现/推荐流 | 与内容同款卡片，角标「广告」+ 关闭，频次 ≤ 1/8 条 | 低（原生融合） |
| **品牌展示区** | 商城顶部横幅 / 个人中心简介 | 品牌旗舰位，非全屏弹窗 | 极低 |
| **电商入口（小黄车）** | 视频左下商品胶囊 + 详情挂车 | 默认折叠，点击才展开 | 低（按需触发） |
| **收益中心** | 个人中心收益卡 | 仅作者可见，激励生产 | 无（用户资产） |
| **直播挂车** | 直播流常驻商品卡 | 直播天然带货场景 | 可控 |

**红线**：首页/播放**禁止**全屏弹窗广告、禁止自动跳转外链、禁止遮挡点赞/评论等核心操作区。所有商业化元素统一在右下/左下边缘或独立页面，与中央内容区物理隔离。

## 五、单手操作与多机型适配

### 5.1 拇指可达区（核心操作映射）
- **左侧下 1/3**：视频文案、商品胶囊（自然落点）。
- **右侧下 1/3**：点赞/评论/收藏/转发 + 关注（竖向操作栏，拇指右滑即可）。
- **底部正中**：发布「＋」按钮（最大热区）。
- **底部 Tab 栏**：5 项均在拇指横扫范围内。
- 高频动作（切条、赞、评、发、购）全部落在手机下半屏 300px 半径弧内——原型中可点「👍 拇指可达区」可视化验证。

### 5.2 适配策略
- **移动优先 + 流式尺寸**：字号 `clamp()`、间距 `clamp()`，避免固定 px 在大屏过小/小屏溢出。
- **安全区**：`env(safe-area-inset-*)` 适配刘海/灵动岛/底部 Home 条，Tab 栏高度 `56px + safe-bottom`。
- **断点**：320–375（小屏，单列优先）、376–428（主流，当前原型尺寸）、429–480（大屏，信息流可加侧边信息）、≥481（平板/折叠，双列信息流 + 侧栏导航）。
- **一致性**：设计令牌统一，组件跨机型等比缩放；状态栏/导航/安全区自动适配，保证不同机型视觉一致。

## 六、无障碍与验收标准

### 6.1 无障碍（WCAG AA）
- 对比度正文 ≥ 4.5:1、大字 ≥ 3:1（本方案 17:1+ 超标）。
- 触控目标 ≥ 44×44px（Tab/操作栏图标 46–48px 达标）。
- 键盘/读屏：语义化标签 + ARIA（`role=dialog` 抽屉、`aria-label` 图标按钮）；焦点环清晰。
- 动效：`@media (prefers-reduced-motion: reduce)` 关闭非必要动画。
- 文本缩放：布局支持 200% 缩放不破版。

### 6.2 设计验收（上线前）
- 核心操作 100% 落在拇指热区；新用户 3 步内完成「看→赞→发」。
- 暗/明主题对比度自动校验通过；品牌橙/电商金不混用。
- 商业化元素零遮挡核心操作、零全屏弹窗广告。
- 主流机型（iPhone SE/14/15 Pro Max、主流安卓 1080p/2K）截图回归一致。
