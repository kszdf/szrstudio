# 对外域名登录 · 落地手册（www.zmgen.cn → 慧根堂工作台）

> 目标：让同事/客户都用 **https://www.zmgen.cn** 打开工作台登录页干活。
> 现状（已核实）：域名已解析到 124.222.33.233；云端 nginx 已跑；Let's Encrypt 证书已有(zmgen.cn)；
> frp 隧道 studio-8385 已把 云端:8385 转发到本机工作台 —— 只差把 www.zmgen.cn 挂到 8385。

## 方案一（立即，1 分钟）· 开 8385 端口
阿里云控制台 → ECS(124.222.33.233) → 安全组 → 入方向 → 手动添加：
```
协议: 自定义 TCP   端口: 8385/8385   授权对象: 0.0.0.0/0
```
之后即可访问：**http://zmgen.cn:8385**（工作台登录页，含注册试用）。
适合先让同事用；无 https、非 www 域名。

## 方案二（正式，推荐）· https://www.zmgen.cn
云端 SSH 操作（5 分钟，按顺序）：
```bash
# 1) 放配置
vi /etc/nginx/sites-available/www.zmgen.cn        # 内容见 云端nginx_www.zmgen.cn.conf
ln -s /etc/nginx/sites-available/www.zmgen.cn /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx

# 2) 把 www.zmgen.cn 并入证书（复用现有 Let's Encrypt 证书，自动续期）
certbot certonly --nginx -d zmgen.cn -d www.zmgen.cn
systemctl reload nginx
```
完成后：**https://www.zmgen.cn** = 工作台登录页（含"注册试用账号"）。
账号体系已就绪：超级管理员 admin/admin888；注册即开通独立试用空间。
