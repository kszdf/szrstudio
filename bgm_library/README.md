# BGM 授权曲库（bgm_library）

本目录存放**已订阅 / 已授权**的背景音乐 mp3，供「滚动字幕卡」出片时按情绪自动混入人声。

## 使用方式
出片界面「🎬 字幕与剪辑设置 → 背景音乐」选情绪即可，后端自动映射到对应文件：

| 下拉选项 | 文件名 | 适用场景 |
|---|---|---|
| 轻快 | `bgm_library/light.mp3` | 口播 / 知识类 |
| 励志 | `bgm_library/inspire.mp3` | 案例 / 成果展示 |
| 舒缓 | `bgm_library/calm.mp3` | 政策解读 |
| 科技感 | `bgm_library/tech.mp3` | 数据 / 系统演示 |
| 悬疑 | `bgm_library/suspense.mp3` | 风险 / 稽查警示 |

- 文件**缺失则自动跳过 BGM**（不报错、不中断出片）。
- **数字人出片暂不支持 BGM**（make_avatar_video 无 --bgm 参数），仅滚动字幕卡支持。

## 推荐订阅（版权干净、可商用）
- **Epidemic Sound**（国际，全平台一键授权，曲库大、情绪分类清晰，约 $15/月）→ 下载后按上表命名放入本目录即可。
- **Artlist**（国际，年付买断式授权，风格统一）。
- **100audio / 包图网 / 摄图网**（国内，中文版权音乐，按曲或包购买，授权条款明确适配抖音 / 视频号 / 小红书）。
- 免费替代（谨慎商用）：YouTube Audio Library / Pixabay Music，质感受限且需自行核对授权范围。

## 注意
1. 务必使用**已授权**音乐，避免平台下架或侵权纠纷。
2. 文件命名严格为 `<key>.mp3`（key = light / inspire / calm / tech / suspense），多一个字都不会被识别。
3. 一首曲子可重复用于多条视频，前提是订阅授权覆盖该用途。
